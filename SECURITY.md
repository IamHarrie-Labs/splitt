# Security policy

Splitt is a public Arc Testnet preview. It is not approved for production funds. The deployed V1 vault and the V2 mainnet candidate have not received an independent security audit.

## Report a vulnerability

Use [GitHub's private vulnerability reporting form](https://github.com/IamHarrie-Labs/splitt/security/advisories/new). Do not open a public issue for an exploitable vulnerability and do not include private keys, seed phrases, API keys or confidential business information.

Include the affected URL, commit or contract address; the smallest reproducible example; the likely impact; and any transaction hash that is already public. Use a public [GitHub issue](https://github.com/IamHarrie-Labs/splitt/issues) for ordinary product defects and documentation corrections.

## Scope

The supported release is the current public testnet site and API. The `ProjectVaultV2` contract is a review candidate, not a deployed or supported mainnet contract. Mainnet deployment remains blocked until the controls in [`docs/mainnet-readiness.md`](docs/mainnet-readiness.md) are complete.
