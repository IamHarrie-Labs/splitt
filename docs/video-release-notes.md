# Splitt film release notes

The film is 90 seconds at 1080p: a narrated motion-design piece with an original pop track generated in code and word-by-word captions (`video/public/captions.srt`). It walks through the illustrative underpayment and remainder example, owner signing, project isolation, and what every payout runs on (Arc, USDC, Circle and owner or multisig signatures), and closes on the Arc mainnet launch.

Illustrative scenes carry an "Illustrative example" badge. The film shows no transaction figures, because the only ones recorded so far are from testnet. It contains no private keys, account screens or customer data.

- Render: `video/out/splitt-film.mp4` (90 seconds, 1920×1080 H.264, stereo AAC). Build steps are in `video/README.md`.
- Website: https://www.usesplitt.xyz
- Live testnet app: https://www.usesplitt.xyz/start
- Wallet-free demo: https://www.usesplitt.xyz/demo
