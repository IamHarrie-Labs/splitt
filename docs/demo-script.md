# Splitt: receipt to review — recording script

Target: 2 minutes 40 seconds. Record the current application. This script is not a recording and the older video is not evidence of the new worker.

| Time | Screen/action | Narration and evidence |
|---|---|---|
| 0:00–0:15 | Project invoice and contractor obligations | “The client paid part of the invoice. Two contractors are waiting, and the project needs a reserve.” |
| 0:15–0:40 | Testnet receipt activity, then automatic draft | Show the actual indexed receipt and resulting draft notification without clicking Propose allocation. “The worker notices the receipt, checks current project facts and drafts the allocation.” If the API is unavailable, demonstrate the public demo and label it as a demo; do not imply it is live worker footage. |
| 0:40–1:00 | Amounts and reserve | Show the full obligation, permitted partial payment and reserve. Point to validated facts. “The proposal spends only this project's available balance.” |
| 1:00–1:20 | Owner wallet review | “Automation stops here. I review and sign the exact recipients and amounts.” Use a real owner signature only after reviewing the batch; otherwise show the demo and label it. |
| 1:20–1:40 | Circle execution and explorer | Show confirmed hashes and execution IDs. Existing proof transactions can be identified as earlier testnet evidence. Do not portray them as just generated by the new worker. |
| 1:40–2:00 | Remainder arrives and fresh draft | Show only the unpaid contractor balance in the next plan. Compare the other project's unchanged balance. |
| 2:00–2:20 | Client-note analysis | Show the quoted remainder statement and invoice/amount checks. Say this is a suggestion requiring review. One synthetic benchmark improved from 7/10 to 9/10 with the tested model and fallback; no claim of production model accuracy. |
| 2:20–2:40 | Pilot evidence and closing | Show a real consenting participant's feedback only if available. Otherwise show the intake and state that verified pilot adoption is still pending. End on repository and deployed URL. |

Before recording, run the checks, confirm the API/network state and remove secret-bearing tabs. Keep the final video under three minutes. Publish to a host accepted by the form; the user fills and submits the form.
